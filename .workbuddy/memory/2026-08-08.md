### 关键技术发现（重要，避免重复踩坑）
抖音开播状态可通过公开接口获取，**无需 a_bogus/X-Bogus 签名**：

- 接口：`GET https://live.douyin.com/webcast/room/web/enter/`
- 必需参数：`aid=6383` + `web_rid={抖音号}` + 一组浏览器环境参数
- 必需前置：先 `GET https://live.douyin.com/` 获取 `ttwid` cookie（无需登录）
- 必需请求头：Chrome UA + `Referer: https://live.douyin.com/`

**字段语义**（已实测）：
- `data.room_status`：0=在播，2=不在播
- `data.data[0].status`：2=在播，4=已结束
- 代码中双字段互相印证判断在播（抖音偶尔只更新其一）
- `data.user.nickname` 即使未开播也返回，可用于校验抖音号填对了

**重要结论**：`web_rid` 就是主播的**抖音号本身**，不必等开播去复制直播间链接。

**已知不可用**：
- `webcast/web/partition/detail/room/` 分区列表接口返回 444 Access Denied（风控）
- `webcast/web/feed/pack/` 返回 "url doesn't match"
- 直播间 HTML 页面数据在 `self.__pace_f` 中且转义，解析麻烦，不如直接用 enter 接口

- 修复：① serve.py 的 `_json` 加 `Access-Control-Allow-Origin: *` 等 CORS 头，并新增 `do_OPTIONS` 处理预检（POST 带 json Content-Type 会触发预检）；② 前端改为"http/https 协议下直接 enableEdit + 仍尝试 health 握手"双保险。重启 serve（task 6buZYA）后验证：health 返回 CORS 头、OPTIONS 预检 204 正常。
- 结论：编辑键现在在同源和预览面板下都可见；file:// 直接打开仍不显示（设计如此，无后端写接口）。
